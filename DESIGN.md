# Отмена устаревших запросов
Отмена устаревших запросов реализована через передачу в `fetch` в качестве параметра `AbortSignal`. Если в процессе выполнения запроса пользователь делает новый запрос, то перед новым запросом вызывается метод `abort()` класса `AbortController`.

# Выбор времени задержки в debounce
Выбранное время задержки для функции `debounce` - 500 мс. Средняя скорость ввода пользователя 300-400 мс/символ (информация из Google). Соответственно, время для debounce должно быть чуть больше. Если еще увеличить время задержки, то это выглядит как неплавный ("тормознутый") интерфейс.

# Сложность (Big O) для mapCountryResponse
Для приведения к интерфейсу`Country` результатов запроса использовался метод массивов `map`, сложность которого O(n).
